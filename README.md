# Cómputo Científico - Doctorado
[![.github/workflows/latex.yml](https://github.com/Gerar93Dot/Computo-cientifico-ok/actions/workflows/latex.yml/badge.svg)](https://github.com/Gerar93Dot/Computo-cientifico-ok/actions/workflows/latex.yml)
## Proyecto 1 

Repositorio destinado no solo a las prácticas, algoritmos y documentación desarrollados para la asignatura de Cómputo Científico en el programa de Doctorado (UANL), sino también para aprender.

## Estructura de carpetas
La organización del repositorio es la siguiente:
* `src/`: Scripts de código fuente y algoritmos.
* `data/`: Datos de entrada y resultados generados.
* `docs/`: Documentos de investigación, reportes y archivos de LaTeX.
* `notebook/`: Cuadernos de experimentación.
## Cómo reproducirlo
1. Clona este repositorio localmente usando: `git clone https://github.com/Gerar93Dot/Computo-cientifico-ok.git`
2. Navega al directorio del proyecto: `cd Computo-cientifico-ok`
3. Ejecuta los scripts o revisa la documentación en sus respectivas carpetas (`src/`, `docs/`).
